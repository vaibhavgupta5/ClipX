ClipZ owns scene data and capture; the pinned HyperFrames GSAP frame adapter owns
seeking a paused timeline. Reviewed templates receive typed content, never executable
source code. Fonts are bundled from pinned Fontsource packages (OFL); final rendering
blocks network requests. Run `npm ci && npm run build` here and install Playwright's
Chromium through the Python project's `showcase` extra.

The host verifies font/image readiness, text fitting, protected regions, random-order
pixel determinism, encoded frame counts and silent scene output. Full-page visuals
reserve their lower section for captions; panel scenes leave the speaker beneath them.
The same compiled runtime is used by the authenticated Studio scene preview.
